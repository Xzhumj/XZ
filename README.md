# XZ

这是 `XZ-video` Codex Skill 的公开仓库，只包含 Skill 定义和执行代码。

## 不包含的素材

本仓库不包含模板、预览片、音频、字体、图片、视频或其他第三方素材。使用前需要自行准备合法授权的素材库。

## 安装

```powershell
Copy-Item -Recurse -LiteralPath . `
  -Destination "$env:USERPROFILE\.codex\skills\xz-video"
```

安装后在 Codex 中使用：

```text
$xz-video
```

本仓库当前未附开源许可证。除仓库内已有第三方声明外，默认保留全部权利。
